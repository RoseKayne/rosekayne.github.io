Gmail CLI

Gmail CLI is a personal command-line tool that connects to the Google Gmail API.

It lets its owner list and read incoming email messages and download message attachments to local storage. It does not send, modify, or delete emails by default.

  • Purpose: Personal use — reading Gmail and saving attachments
  • Data accessed: Gmail mailbox (read-only scope)
  • Data storage: Locally on the owner's computer only
